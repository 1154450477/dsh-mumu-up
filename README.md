# dsh-mumu-up —— 手机唤醒器

DSH 插件。**判定条件跟 [dsh-speak-up](https://github.com/Yuuyuko-uu/dsh-speak-up) 一模一样**，
区别只有最后那一下：speak-up 掷中了是「找她搭话」，本插件掷中了是「叫她去玩手机」。

- 掷骰子的是**本地**的（不花模型 token）；掷中了才走 DSH 正常的一轮（人格、历史、工具、记忆全是她自己的）。
- 她玩手机用的是 [mumu-mcp](https://github.com/1154450477/dsh-mumu-mcp)（MCP server + 本机控制口 8791）。

## 判定条件（跟 speak-up 逐条对齐）

每 `间隔分钟` 掷一次 0~100 的数，**掷到命中线以下才唤醒**：

```
命中线 = min(100, 档位命中线 × 时机因子 + min(加成上限, 连没中 × 没中加成))
```

| 条件 | 跟 speak-up 一致的口径 |
| --- | --- |
| 峰时 / 谷时 | 时段**写死**：周一~周五 09:00–12:00、14:00–18:00 是峰时，其余（含周末）全是谷时 |
| 峰时命中线 / 谷时命中线 | 这两个数**不是概率**，是「基础命中线」 |
| 没中加成 / 加成上限 | 没掷中一次下一次命中线加这么多；掷中清零 |
| 时机因子 | 距她上次**玩**不到近阈值分钟 → ×近因子（默认 20 分钟 ×0.15，刚玩过就少玩）；超过远阈值分钟没玩 → ×远因子（默认 360 分钟 ×1.5，冷太久了就多玩）；否则 ×1 |
| 安静时段 | `安静起`~`安静止`（含起不含止，跨午夜也认；起 === 止 = 不启用） |
| 手机冷却 | 她刚玩过手机，`手机冷却分钟` 内不再叫她玩（默认 20；0 = 不冷却；手动按钮不受限制） |
| 目标会话 | 勾哪些会话；掷中一次只在其中一个里叫去玩（挑一个活着又不忙的） |
| 试运行 | 开着就只记账、不真唤醒 |

## 手机专有的三格

| 键 | 默认 | 说明 |
| --- | --- | --- |
| 目标池 | `刷一刷,玩游戏,看抖音,逛taptap` | 唤醒时随机挑一个当「玩什么」，**只有文案里写了 `{目标}` 占位符**才会带进唤醒语（不写占位符＝不带目标） |
| 控制口 | `http://127.0.0.1:8791` | mumu-mcp 的本机控制口，用来问「手机是不是已经在玩」 |
| 手机忙时跳过 | `true` | 手机已经在玩 → 这轮不唤醒（不打断她）。关掉就完全不问控制口 |

### 和 mumu-mcp 闲时自主玩的关系

mumu-mcp 自带一个「闲时自主玩」调度器（`autoplay_enable`，默认关）。**装了本插件就别开它** ——
什么时候玩手机由这里掷骰决定（峰谷命中线 / 没中加成 / 时机因子），mumu-mcp 不再自己定时开，
不然两套调度会重复叫她玩。定时计划（`mumu_phone_autoplay schedule`）不受影响，照常到点开。

## 装

```bash
dsh plugin --profile web add github:1154450477/dsh-mumu-up
```

装完**重启 DSH**才生效。设置页在 **DSH 设置 → 插件 → 手机唤醒器**。

配置文件：`%USERPROFILE%\.dsh\mumu-up-config.json`（也可以直接在设置页改）。

## 怎么用

1. 设置页里勾上**目标会话**（大肥鱼那个），填好**唤醒文案**（想要目标就写 `{目标}` 占位，不想带就删掉占位符，她会原样收那句话）。
2. 先开着**试运行**看几轮记录（每轮都写清楚「掷出多少 / 命中线多少 / 怎么算出来的」）。
3. 确认时机合适了，把**试运行**关掉 → 掷中就真唤醒。

## 跟 speak-up 的差别（只有这一条）

speak-up 掷中 → 往会话里送一句「好久没人跟我说话了」。
本插件掷中 → 往会话里送一句「手机在桌上没人管，我玩会儿去——刷一刷」，
**由她自己**决定要不要调 `mumu_phone_play` 去玩（跟真人被催着玩一样，她可以不理）。

## 已知限制

- 唤醒只是「说一句话」，不直接开手机 —— 真开手机还是她自己的 `mumu_phone_play`。
- 问不到控制口时按「没在玩」处理（宁可多唤醒一次，也不卡住不动）。
- 「连没中」只存在内存里：DSH 一重启就回到 0。
